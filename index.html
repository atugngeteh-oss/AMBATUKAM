Buka Safelink

Tempel link safelink, dapatkan tujuan akhirnya tanpa membuka halaman iklan.

Pengaturan proxy (opsional)

Browser memblokir pembacaan halaman situs lain (CORS). Tanpa proxy, tool ini hanya bisa membaca tujuan yang sudah tertanam di URL. Isi alamat Cloudflare Worker milikmu agar halaman safelink bisa dibaca dan dianalisis.

Kode Cloudflare Worker 
export default {
  async fetch(req) {
    const u = new URL(req.url).searchParams.get("url");
    const cors = {"Access-Control-Allow-Origin": "https://DOMAIN-KAMU.com"};
    if (!u || !/^https?:\/\//.test(u)) return new Response("url?", {status: 400, headers: cors});
    const r = await fetch(u, {redirect: "follow", headers: {"User-Agent": "Mozilla/5.0"}});
    return new Response(await r.text(), {headers: {...cors, "X-Final-Url": r.url}});
  }
}

Ganti DOMAIN-KAMU.com dengan domain tempat file ini di-hosting agar proxy tidak dipakai orang lain.
